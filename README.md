## ✨ Fonctionnalités

- Présentation personnelle et parcours
- Compétences techniques
- Projets réalisés
- Informations de contact
- Génération / téléchargement du CV en PDF
- Design responsive (mobile, tablette, ordinateur)

## 🛠️ Technologies

- HTML5, CSS3, JavaScript
- [Font Awesome](https://fontawesome.com/) et police Poppins (Google Fonts)
- [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) pour l'export PDF
- Hébergement : GitHub Pages

## 📁 Structure du projet

```
Mon-premier-projet/
```

## 🚀 Lancer le projet en local

```bash
git clone https://github.com/bankou224/Mon-premier-projet.git
cd Mon-premier-projet
```

Puis ouvre `index.html` dans ton navigateur.
